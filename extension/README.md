# PrismVault 网页摘取（浏览器扩展）

把网页上的图片和视频一键存进 [PrismVault](../../README.md) 的当前图库。数据只在
`浏览器 → 127.0.0.1 → 你电脑上的图库` 之间流动，不经过任何服务器。

## 安装

1. 打开 PrismVault → **设置 → 浏览器扩展** → 点「导出扩展」→ 选一个文件夹；
2. 得到 `prismvault-extension` 文件夹后，在浏览器地址栏打开：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
   - 其它 Chromium 内核浏览器类似
3. 打开右上角「开发者模式」；
4. 点「加载已解压的扩展程序」，选中刚才的 `prismvault-extension` 文件夹；
5. 点扩展图标 →「扩展设置」→ 填入 PrismVault 设置面板里的**端口**与**访问令牌** →
   「测试连接」显示「连接正常」即可。

> 装好扩展后，已经打开的网页需要刷新一次才会有悬停按钮和快捷键（浏览器不会
> 给已存在的页面补注入脚本）。

## 三种用法

| 方式 | 操作 | 适合 |
| --- | --- | --- |
| 整页挑选 | 点扩展图标 →「打开采集面板」，或任意网页按 `Alt` + `S` | 一页里挑几张 |
| 单张速存 | 鼠标悬停在图片左上角，点浮出的方块 | 逛图站顺手存 |
| 右键菜单 | 图片 / 视频上右键 →「保存到 PrismVault」 | 最快的一步 |
| 截取整页 | 面板里点「截取整页」、页面空白处右键 →「截取此页到 PrismVault」，或 `Alt` + `Shift` + `S` | 文章 / 长榜单留一份 |

面板里支持「全选 / 清空 / 反选」，勾完点「保存到 PrismVault」。

## 面板里的「存放位置」

面板顶部有「文件夹」和「标签」两行，挑图的同时就把归档做掉：

- **文件夹**：下拉里是库里已有的目录，外加「库根目录」和「自动：example.com」
  （按站点规则，默认）。点右边的 `＋` 可以直接打新目录名，多级用 `/` 分隔
  （如 `2026/风景`），目录不存在会在保存时自动建出来。
- **标签**：逗号分隔（中文逗号、顿号也认），回车或失去焦点即生效；下面列着库里
  已经用过的标签，点一下切换。库里没有的标签会在保存时现建，`a/b` 会自动补父级。

这两项会记在扩展本地（`chrome.storage.local`），下次打开面板还是上次的选择。

## iframe 与重试

- 页面里的 iframe（画廊、图床、嵌入的播放器）也会被扫描，顶层面板会把各帧的结果
  按 URL 合并去重。面板只在顶层文档出现，不会在广告位里冒出来。
- 每张图最多尝试 3 次（网络抖动 / 5xx 会退避重试）；仍然失败的会记住，面板底部出现
  「重试 N 项」，只重跑那几张。库没打开、请求体为空这类 4xx 错误不重试。

## 截取整页

三个入口：采集面板里的「截取整页」、页面右键 →「截取此页到 PrismVault」、
快捷键 `Alt` + `Shift` + `S`。存下来的是一张长图（`<站点>-20261028-143012.jpg`），
落在面板当前选的文件夹里、挂当前填的标签。

做法是逐屏截 + 拼一张：先滚到顶部、藏掉页面滚动条，然后每 520ms 拍一屏
（Chrome 对截屏 API 有限流），拼的时候第一屏保留页头，从第二屏起把 `fixed` /
`sticky` 的导航条藏掉 —— 否则拼出来是十几条重复的页头。

- 页面本身只有一屏高：直接就是一张视口截图；
- 超过 **16 屏**（约 16000px）：只截前 16 屏并提示，长图高度不会留白；
- 高度超过 16384px：整体等比缩小（浏览器画布上限），宽度同步缩；
- 内容是塞在页面内部滚动容器里的（部分 SPA）：只截可视区，不硬拼错位图。

## 会自动处理的情况

- `srcset` 多分辨率：取最大那一档，不会把缩略图当原图存
- 懒加载图：识别 `data-src` / `data-original` / `data-lazy-src`
- CSS 背景图、`<picture>`、指向图片的链接
- `blob:` 地址（canvas 画出来的图、流媒体）
- 需要登录 / 防盗链的图：由扩展带着 cookie 去取，比直接下载更靠谱
- 同名文件自动加 `(2)`，不会覆盖

## 保存到哪

默认按站点建子文件夹（`库根/example.com/图片.jpg`），可在扩展设置里改成固定
子文件夹或直接存库根。网页来源会写进文件的「备注」，方便回溯。

## 限制

- 单个文件上限 512 MB；
- 视频只保存原文件，缩略图由系统播放器负责（PrismVault 里显示为可播放卡片）；
- PrismVault 没打开图库时扩展会明确提示，不会把文件丢到不知道哪去；
- 面板里的文件夹清单最多列 3 层、400 条（更多的目录请直接在 `＋` 里打路径）；
- 截屏期间请别切走标签页（截图拍的是当前活动标签页），也尽量别滚动鼠标。
