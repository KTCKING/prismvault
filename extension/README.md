# PrismVault 网页摘取（浏览器扩展）

把网页上的图片和视频一键存进 [PrismVault](../../README.md) 的当前图库。数据只在
`浏览器 → 127.0.0.1 → 你电脑上的图库` 之间流动，不经过任何服务器。

## 安装

1. 打开 PrismVault → **设置 → 浏览器扩展** → 点「导出扩展」→ 选一个文件夹；
2. 得到 `prismvault-extension` 文件夹后，在浏览器地址栏打开：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
   - 其它 Chromium 内核浏览器类似
3. 打开右上角「开发者模式」；
4. 点「加载已解压的扩展程序」，选中刚才的 `prismvault-extension` 文件夹；
5. 点扩展图标 →「扩展设置」→ 填入 PrismVault 设置面板里的**端口**与**访问令牌** →
   「测试连接」显示「连接正常」即可。

> 装好扩展后，已经打开的网页需要刷新一次才会有悬停按钮和快捷键（浏览器不会
> 给已存在的页面补注入脚本）。

## 三种用法

| 方式 | 操作 | 适合 |
| --- | --- | --- |
| 整页挑选 | 点扩展图标 →「打开采集面板」，或任意网页按 `Alt` + `S` | 一页里挑几张 |
| 单张速存 | 鼠标悬停在图片左上角，点浮出的方块 | 逛图站顺手存 |
| 右键菜单 | 图片 / 视频上右键 →「保存到 PrismVault」 | 最快的一步 |

面板里支持「全选 / 清空 / 反选」，勾完点「保存到 PrismVault」。

## 会自动处理的情况

- `srcset` 多分辨率：取最大那一档，不会把缩略图当原图存
- 懒加载图：识别 `data-src` / `data-original` / `data-lazy-src`
- CSS 背景图、`<picture>`、指向图片的链接
- `blob:` 地址（canvas 画出来的图、流媒体）
- 需要登录 / 防盗链的图：由扩展带着 cookie 去取，比直接下载更靠谱
- 同名文件自动加 `(2)`，不会覆盖

## 保存到哪

默认按站点建子文件夹（`库根/example.com/图片.jpg`），可在扩展设置里改成固定
子文件夹或直接存库根。网页来源会写进文件的「备注」，方便回溯。

## 限制

- 单个文件上限 512 MB；
- 视频只保存原文件，缩略图由系统播放器负责（PrismVault 里显示为可播放卡片）；
- PrismVault 没打开图库时扩展会明确提示，不会把文件丢到不知道哪去。
